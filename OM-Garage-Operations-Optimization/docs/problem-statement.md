# Problem Statement

An automotive detailing and ceramic-coating garage must coordinate incoming cars across parking, washing, paint correction, coating and interior-cleaning activities. The number of workers and parallel workstation capacity can influence the time required to process a batch and the rate at which completed cars leave the system.

This simulator provides a simplified way to explore how simultaneous arrivals, permanent and temporary staffing, and coating packages affect the modelled cycle time, flow time, throughput and indicative financial contribution.

## Decision questions
- Which station is the current modelled bottleneck?
- How does adding workers change station time and system cycle time?
- How does the number of simultaneously arriving cars affect parallel capacity?
- What is the indicative labour cost per completed car under the model assumptions?

The application is a learning prototype. It does not claim to represent a measured or validated garage operation.
